# HR Attrition Analysis and Prediction

## Overview
This project analyzes employee data to understand the reasons behind attrition and predict whether an employee is likely to leave the company. It focuses on using data analysis and machine learning to support better HR decisions.

## Objective
- Identify key factors influencing employee attrition
- Perform exploratory data analysis to find patterns
- Build a predictive model for attrition

## Tools and Technologies
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn

## Workflow
1. Data cleaning and preprocessing
2. Exploratory Data Analysis (EDA)
3. Feature selection
4. Model building and evaluation

## Key Insights
- Employee satisfaction and work environment have a strong impact on attrition
- Salary and job role also influence employee decisions
- Data visualization helped in understanding patterns clearly

## Outcome
Successfully built a model to predict employee attrition and gained insights that can help organizations improve retention.

## Future Improvements
- Improve model accuracy with advanced algorithms
- Create an interactive dashboard
- Deploy the model as a web application
